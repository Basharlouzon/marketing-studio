The skills

Five skills, one studio

Each skill is a folder with a SKILL.md (loaded by ZCode), bundled scripts, and on-demand references. Docs are pre-rendered from the shipped files at build time — they can't drift.

skill 0

inspiration-intake

Asks the user what he's looking for, then scans the internet for current trends — before any concept lock. Writes INTAKE.md + INSPIRATION.md.

Pipeline

How a campaign runs

1Intake — ask the user + scan trends
→
2Concept lock on real calendar moments
→
3Agent waves — Director, Writer, Directors
→
4Build — images + motion videos
→
5Judge gate — fix loop — ship

Every asset passes a stateless visual-judge pass with evidence-based verdicts. Failing assets are grouped by root cause, fixed once, re-rendered, and re-judged. The gate is the product.

Port it

Onboard any app in 3 steps

1

Copy the template

cp -r templates/brand-kit-template skills/<app>-brand-kit/ and fill the placeholders — extract the app's exact colors from its CSS, its logo, its real facts.

2

Scaffold the workspace

assets/ + strategy/ + images/ + one gen_*.py generator (clone patterns are in the brand kit).

3

Run the studio

"Make 12 posts for {app} for December" — it asks what you're looking for, researches trends, builds, and judges.

Install

Get the skills

$ git clone https://github.com/Basharlouzon/marketing-studio.git && cd marketing-studio && ./install.sh

install.sh is idempotent and safe to re-run — it copies the 5 skills into ~/.zcode/skills/. Restart ZCode — done.
