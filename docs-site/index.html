How to start

Your first campaign in 3 steps

  1. 1

    Install

    Paste this into your terminal, then quit and reopen your agent so it loads the skills.

    git clone --depth 1 https://github.com/Basharlouzon/marketing-studio.git && bash marketing-studio/install.sh
  2. 2

    Add your brand

    Tell your agent where your product lives. It fills the brand-kit template with your real colors, logo and facts.

    Build a brand kit for my product from marketing-studio/templates/brand-kit-template. My site: https://…
  3. 3

    Ask for a campaign

    It asks 3–4 quick questions, checks current trends, builds the assets, and judges each one before you see it.

    Make 12 Instagram posts for my product for December.

How it works

Five skills, one line of production

Each skill is a folder with a SKILL.md your agent loads, plus bundled scripts. The docs are rebuilt from those files on every deploy, so they match the code.

  1. 0IntakeAsks what you want, scans current trends.inspiration-intake
  2. 1BrandExact colors, real facts, voice, layout rules.brand-kit
  3. 2ImagesPosts, stories, thumbnails at exact sizes.social-image-studio
  4. 3MotionReal animated reels, rendered in Remotion.remotion-motion-studio
  5. 4Judge & shipExpert agents run it; a visual judge gates every asset.marketing-agent-studio

The judge gate

Every asset gets a pass or fail with evidence: cut-off text, dead space, broken images, weak contrast. Fails are grouped by root cause, fixed once, re-rendered and judged again. Nothing under 9.0/10 reaches you.

Install once. Ask for a campaign.

$ git clone --depth 1 https://github.com/Basharlouzon/marketing-studio.git && bash marketing-studio/install.sh

Using Claude Code? Pick it in the tabs at the top, or add SKILLS_DIR=~/.claude/skills before bash marketing-studio/install.sh.
