Five skills, one studio

Each skill is a folder with a SKILL.md (loaded by ZCode), bundled scripts, and on-demand references. Docs render the shipped files directly — they can't drift.

How a campaign runs

1Intake — ask the user + scan trends
→
2Concept lock on real calendar moments
→
3Agent waves — Director, Writer, Directors
→
4Build — images + motion videos
→
5Judge gate — fix loop — ship

Every asset passes a stateless visual-judge pass with evidence-based verdicts. Failing assets are grouped by root cause, fixed once, re-rendered, and re-judged. The gate is the product.

Onboard any app in 3 steps

1

Copy the template

2

Scaffold the workspace

assets/ + strategy/ + images/ + one gen_*.py generator (clone patterns are in the brand kit).

3

Run the studio

"Make 12 posts for {app} for December" — it asks what you're looking for, researches trends, builds, and judges.
